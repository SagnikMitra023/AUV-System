# AUV-System
Developed a prototype **Autonomous Underwater Vehicle (AUV) Inspection System** integrating computer vision, sensor fusion, embedded control, and robotic actuation. The system uses dual ESP32-CAMs for underwater image acquisition, with **Canny edge detection, contour extraction, and Inner Moore Boundary Tracing** for structural feature analysis, along with a **Structured Forest-based vision module** for defect detection. An **Extended Kalman Filter (EKF) was implemented and tested on recorded IMU, DVL, and GPS datasets** to estimate the AUV's position and velocity, with the resulting trajectory evaluated against GPS reference data. The Arduino-based control system operates **3 servo motors, 4 pumps, 4 solenoid valves, and a propeller** to execute pitch, yaw, roll, vertical, and forward movements, while the inspection prototype additionally integrates a 3-servo robotic arm and pump for basic defect repair. The project demonstrates the integration of **computer vision, state estimation, embedded systems, and robotic manipulation** for underwater inspection applications.
